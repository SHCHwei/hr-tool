# 月打卡記錄表輸入系統 (Clock-in Management System)

本專案為一個使用 Python 打造的月度打卡表輸入與考勤試算管理工具。支援圖形化每日打卡時間輸入，並自動依據考勤規則試算「加班時數」與「早退時數」，匯出排版精美的 Excel 報表。

---

## 🌟 主要功能特點

1. **依月份動態生成日期（1號至最後一號）**：
   - 選擇年份與月份後，自動根據月曆天數（28, 29, 30 或 31 天）生成每日打卡列。
   - 自動標註星期（星期一至星期日），並對週末（週六、週日）進行背景色彩著色區隔。

2. **每日四格輸入框**：
   - **首次上班** (上午上班)
   - **首次下班** (午休下班)
   - **二次上班** (下午上班)
   - **二次下班** (當日下班)
  - **輸入格式**：使用 24 小時制四位數 `HHMM`，例如 `08:30` 請輸入 `0830`；格式或時間無效時欄位會清空。

3. **便捷輸入輔助工具**：
   - **清空表格**：一鍵重設所有輸入內容。

4. **視窗底部匯出 Excel 功能（含考勤時數試算）**：
   - 點擊「匯出 Excel 打卡表」按鈕，自由選擇檔案儲存路徑。
   - 自動生成具有排版、主題色彩標題、邊框與自動欄寬格式的專業 `.xlsx` 報表。
   - 試算表最右方自動新增 **「加班時數」** 與 **「早退時數」** 兩欄位，並自動完成精確時數計算。

5. **PySide6 (Qt) 圖形介面**：
  - 使用 PySide6 提供的桌面介面輸入打卡資料並匯出報表。

## ⏱️ 加班與早退計算規則說明

本系統之加班與早退邏輯參考自 `GoLang_practise/HR/main.go` 規範，具體計算與判定規則如下：

### 1. 考勤基準時間
| 項目 | 基準時間點 | 說明 |
| :--- | :--- | :--- |
| **上班基準時間** (`workStart`) | `08:30:00` | 正常上班基準時間 |
| **下班基準時間** (`workOff`) | `17:30:00` | 在此時間之前離開視為早退 (Go 源碼以 `17:29:59` 判斷) |
| **加班起算時間** (`workOver`) | `17:45:00` | 超過此時間離開開始起算加班時數 |

---

### 2. 計算規則詳細說明

#### ① 早退時數 (Early Departure)
- **判定條件**：當日有效下班時間早於 `17:30:00`。
- **計算公式**：
  $$\text{早退時長} = 17:30 - \text{實際下班時間}$$
- **時數格式**：四捨五入至分鐘。若滿 1 小時顯示 `X小時Y分`，未滿 1 小時顯示 `Y分`。
- **範例**：
  - `17:00` 下班 $\rightarrow$ 早退 `30分`
  - `16:30` 下班 $\rightarrow$ 早退 `1小時0分`
  - `12:00` 下班（如請半天假） $\rightarrow$ 早退 `5小時30分`

#### ② 加班時數 (Overtime)
- **判定條件**：當日有效下班時間晚於 `17:45:00`。
- **計算公式**：
  $$\text{加班時長} = \text{實際下班時間} - 17:45$$
- **時數格式**：四捨五入至分鐘。若滿 1 小時顯示 `X小時Y分`，未滿 1 小時顯示 `Y分`。
- **範例**：
  - `18:00` 下班 $\rightarrow$ 加班 `15分`
  - `18:45` 下班 $\rightarrow$ 加班 `1小時0分`
  - `19:10` 下班 $\rightarrow$ 加班 `1小時25分`

#### ③ 正常下班緩衝區間 (Standard 8-Hour Buffer)
- **判定區間**：`17:30 <= 下班時間 <= 17:45`
- **說明**：落在該 15 分鐘區間內視為正常完成標準工時下班，**不計早退亦不計加班**（欄位保留空白）。
- **範例**：`17:30`、`17:35` 或 `17:45` 下班，加班與早退欄位皆為空白。

#### ④ 跨夜 (次日凌晨) 下班規則 (Overnight Shift)
- **判定條件**：下班時間小時數小於 `06:00`（即 `00:00` ~ `05:59`）。
- **說明**：視為夜間跨日加班至次日凌晨，下班時間累加 24 小時後扣除 17:45 加班起算點。
- **範例**：
  - 次日 `00:30` 下班 $\rightarrow$ 加班 `6小時45分`
  - 次日 `01:00` 下班 $\rightarrow$ 加班 `7小時15分`
  - 次日 `05:59` 下班 $\rightarrow$ 加班 `12小時14分`

#### ⑤ 週末出勤加班
- **判定條件**：星期六或星期日有完整的上、下班打卡區間。
- **計算方式**：週末不套用 `17:45` 加班起算時間；首次及二次出勤區間的工時全部計為加班，早退欄位留白。
- **跨午夜區間**：若下班時間早於上班時間，視為下班發生於隔日。
- **不完整區間**：缺少上班或下班打卡的區間不列入工時計算。
- **範例**：`09:00-12:00`、`13:00-17:00` 的週末出勤，計為 `7.0小時` 加班。

#### ⑥ 平日有效下班判定規則
- **雙段出勤**：若有填寫「二次上班」，表示當天下午有出勤，有效下班時間以「二次下班」為準（若二次下班未填，視為未完成下班打卡，不予計算）。
- **單段出勤**：若未填寫「二次上班」，優先取「二次下班」；若無則取「首次下班」（如僅上午出勤半天，或全天僅打兩次卡）。
- **未打卡/放假**：平日若無有效下班打卡，或週末沒有完整出勤區間，加班與早退欄位皆自動保留空白，避免產生誤判。

### 3. Excel 試算表欄位結構

匯出的 `.xlsx` 試算表包含以下 8 個欄位：

| 欄位順序 | 欄位名稱 | 說明 |
| :---: | :--- | :--- |
| 第 1 欄 | **日期** | 格式：`YYYY-MM-DD` |
| 第 2 欄 | **星期** | 星期一至星期日（週末自動著色） |
| 第 3 欄 | **首次上班** | 上午上班打卡時間（例如 `0900`） |
| 第 4 欄 | **首次下班** | 午休下班打卡時間（例如 `1200`） |
| 第 5 欄 | **二次上班** | 下午上班打卡時間（例如 `1300`） |
| 第 6 欄 | **二次下班** | 當日下班打卡時間（例如 `1800`） |
| 第 7 欄 | **加班時數** | 平日晚於 17:45 計算；週末出勤工時全數計入 |
| 第 8 欄 | **早退時數** | 平日早於 17:30 依規則計算；週末留白 |

## 🚀 如何運行

### 1. 安裝套件需求
```bash
pip install -r requirements.txt
```

### 2. 啟動應用程式
```bash
python app.py
```

或直接啟動 PySide6 介面：
```bash
# 直接啟動 PySide6 GUI 介面
python clock_in_app.py
```

### 3. 執行測試
```bash
# 執行 Excel 匯出與考勤計算功能測試
python test_excel_export.py
```
