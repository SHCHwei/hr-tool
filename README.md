# 月打卡記錄表輸入系統 (Clock-in Management System)

本專案為一個使用 Python 打造的月度打卡表輸入與考勤試算管理工具。支援圖形化每日打卡時間輸入，並自動依據考勤規則試算「加班時數」與「早退時數」，匯出排版精美的 Excel 報表。

---

## 🌟 主要功能特點

1. **依月份動態生成日期（1號至最後一號）**：
   - 選擇年份與月份後，自動根據月曆天數（28, 29, 30 或 31 天）生成每日打卡列。
   - 自動標註星期（星期一至星期日），並對週末（週六、週日）進行背景色彩著色區隔。

2. **每日四格輸入框**：
   - **首次上班** 
   - **首次下班** 
   - **二次上班**  
   - **二次下班** 
  - **輸入格式**：使用 24 小時制四位數 `HHMM`，例如 `08:30` 請輸入 `0830`；格式或時間無效時欄位會清空。

3. **便捷輸入輔助工具**：
   - **清空表格**：一鍵重設所有輸入內容。

4. **視窗底部匯出 Excel 功能（含考勤時數試算）**：
   - 點擊「匯出 Excel 打卡表」按鈕，自由選擇檔案儲存路徑。
   - 自動生成具有排版、主題色彩標題、邊框與自動欄寬格式的專業 `.xlsx` 報表。
   - 試算表最右方自動新增 **「加班時數」** 、 **「早退時數」** 、 **「遲到時數」** 三個欄位，並自動完成精確時數計算。

5. **PySide6 (Qt) 圖形介面**：
  - 使用 PySide6 提供的桌面介面輸入打卡資料並匯出報表。

## ⏱️ 加班與早退計算規則說明

以下整理考勤計算規則。平日加班包含首次上班早於 `workStart` 的時間，以及各出勤時段中晚於 `workOff + 15 分鐘` 的工作時間；平日早退與下班後加班使用員工設定的下班基準時間，未提供有效設定時預設為 `17:30`。週末則採不同計算方式。

### 1. 考勤基準時間
| 項目 | 基準時間點 | 說明 |
| :--- | :--- | :--- |
| **上班基準時間** (`workStart`) | 依員工設定 | 首次上班早於此時間的差額計入平日加班；晚於此時間則計算遲到 |
| **下班基準時間** (`workOff`) | 預設 `17:30` | 平日早退判定基準；可由員工設定取代 |
| **加班起算時間** (`workOver`) | `workOff` + 15 分鐘 | 平日有效下班時間晚於此時間時計入下班後加班；預設為 `17:45` |

---

### 2. 計算規則詳細說明

#### ① 早退時數 (Early Departure)
- **判定條件**：平日有效下班時間早於設定的 `workOff`（預設 `17:30`）。
- **計算公式**：
  `早退分鐘 = workOff - 有效下班時間`
- **時數格式**：將分鐘數除以 60，四捨五入至小數點後兩位，以 `X小時` 顯示。小於或等於 0 分鐘時留白。
- **範例**：
  - 預設下班基準 `17:30`，`17:00` 下班 → `0.5小時`
  - 預設下班基準 `17:30`，`16:30` 下班 → `1.0小時`

#### ② 加班時數 (Overtime)
- **判定條件**：平日首次上班早於 `workStart`，或任一出勤時段超過 `workOff + 15 分鐘`（預設 `17:45`）。
- **計算公式**：
  `提前上班分鐘 = max(0, workStart - 首次上班時間)`

  未填「二次上班」時：

  `下班後加班分鐘 = max(0, 有效下班時間 - (workOff + 15 分鐘))`

  有填「二次上班」時，首次下班與二次出勤區間分別計算：

  `首次下班加班分鐘 = max(0, 首次下班 - (workOff + 15 分鐘))`

  `二次出勤加班分鐘 = max(0, 二次下班 - max(二次上班, workOff + 15 分鐘))`

  `加班總分鐘 = 提前上班分鐘 + 首次下班加班分鐘 + 二次出勤加班分鐘`

  二次出勤區間跨午夜時，按跨日時間延續計算。首次下班至二次上班之間的休息空檔不計入加班。
- **時數格式**：分鐘數除以 60，四捨五入至小數點後兩位，以 `X小時` 顯示。
- **範例**：
  - `workStart` 為 `08:30`，首次上班 `08:00`，有效下班 `17:30` → 提前上班 `0.5小時`；下班後沒有加班，當日加班共 `0.5小時`
  - 預設加班起算時間 `17:45`，`18:00` 下班且未提早上班 → `0.25小時`
  - `workStart` 為 `08:30`，首次上班 `08:00`，預設加班起算時間 `17:45`，`18:00` 下班 → 提前上班與下班後加班合計 `0.75小時`
  - `workStart` 為 `08:30`、`workOff` 為 `17:30`，打卡 `08:11`、`18:00`、`19:15`、`22:08` → 提前上班 `19` 分鐘、首次下班加班 `15` 分鐘、二次出勤加班 `2小時53分`，合計 `3小時27分`（`3.45小時`）。

#### ③ 正常下班緩衝區間 (Standard 8-Hour Buffer)
- **判定區間**：`workOff <= 有效下班時間 <= workOff + 15 分鐘`（預設 `17:30` 至 `17:45`）
- **說明**：落在該 15 分鐘區間內，該下班時間本身**不計早退或下班後加班**。若首次上班早於 `workStart`，仍會依提前上班規則計入加班。
- **範例**：使用預設基準且未提早上班時，`17:30`、`17:35` 或 `17:45` 下班，加班與早退欄位皆為空白。

#### ④ 跨夜 (次日凌晨) 下班規則 (Overnight Shift)
- **判定條件**：平日有效下班時間的小時數小於 `6`，即 `00:00` 至 `05:59`。
- **說明**：程式將該下班時間視為次日時間並加上 24 小時，再依平日下班基準與加班起算時間計算。這是依時間小時數判定，並不會根據日期或其他打卡欄位確認是否真的跨日。
- **範例**：
  - 預設加班起算時間 `17:45`，次日 `00:30` 下班 → `6.75小時`
  - 預設加班起算時間 `17:45`，次日 `01:00` 下班 → `7.25小時`
  - `workStart` 為 `08:30`，首次上班 `08:29`、首次下班 `01:30`，若為平日且未填二次上班，會以 `01:30` 作為有效下班時間；下班後加班 `7.75小時`，另加首次上班提前的 1 分鐘，總加班約 `7.77小時`。

#### ⑤ 週末出勤加班
- **判定條件**：星期六或星期日有完整的上、下班打卡區間。
- **計算方式**：週末不套用 `17:45` 加班起算時間；首次及二次出勤區間的工時全部計為加班，早退欄位留白。
- **跨午夜區間**：若某區間的下班時間早於上班時間，視為下班發生於隔日。
- **不完整區間**：缺少上班或下班打卡的區間不列入工時計算。
- **注意**：週末以完整打卡區間的經過時間加總，不會扣除休息時間；如果輸入 `08:29` 至隔日 `01:30` 為同一完整區間，該區間會全部計為加班。
- **範例**：`09:00-12:00`、`13:00-17:00` 的週末出勤，計為 `7.0小時` 加班。

#### ⑥ 平日有效下班判定規則
- **雙段出勤**：若有填寫「二次上班」，首次下班與二次上班至二次下班作為分開的出勤段計算加班；若二次下班未填，仍計算首次下班段及提早上班加班，但不計二次出勤段或早退。
- **單段出勤**：若未填寫「二次上班」，優先取「二次下班」；若無則取「首次下班」（如僅上午出勤半天，或全天僅打兩次卡）。
- **未打卡/放假**：平日沒有有效下班打卡時，不計算下班後加班與早退；若首次上班早於 `workStart`，仍依新增規則計入提前上班加班。週末則只加總完整的上、下班區間。

#### ⑦ 遲到時數 (Late Arrival)
- **判定條件**：首次上班打卡晚於員工設定的上班基準時間。
- **計算方式**：首次上班時間減去上班基準時間；非正數或任一時間無效時留白。
- **時數格式**：與加班、早退相同，分鐘數除以 60，四捨五入至小數點後兩位，以 `X小時` 顯示。

#### ⑧ 時數顯示與計算邊界
- 所有時數都以十進位小時顯示，例如 `30` 分鐘顯示 `0.5小時`、`15` 分鐘顯示 `0.25小時`；不是「小時加分鐘」格式。
- 平日早退依有效下班時間計算；加班由首次上班早於 `workStart` 的時間，以及各出勤段在 `workOff + 15 分鐘` 之後的實際時間相加。雙段出勤時，首次下班與二次出勤段分開計算，不把中間空檔算入加班。首次上班晚於 `workStart` 時另計遲到。
- 跨日平日下班判定只適用於 `00:00` 至 `05:59`。`06:00` 起不會自動加 24 小時。

### 3. Excel 試算表欄位結構

匯出的 `.xlsx` 試算表包含以下 9 個欄位：

| 欄位順序 | 欄位名稱 | 說明 |
| :---: | :--- | :--- |
| 第 1 欄 | **日期** | 格式：`YYYY-MM-DD` |
| 第 2 欄 | **星期** | 星期一至星期日（週末自動著色） |
| 第 3 欄 | **首次上班** | 上午上班打卡時間（例如 `0900`） |
| 第 4 欄 | **首次下班** | 午休下班打卡時間（例如 `1200`） |
| 第 5 欄 | **二次上班** | 下午上班打卡時間（例如 `1300`） |
| 第 6 欄 | **二次下班** | 當日下班打卡時間（例如 `1800`） |
| 第 7 欄 | **加班時數** | 平日提早於 workStart 上班及各出勤段超過 workOff + 15 分鐘的時數合計；週末完整出勤區間工時全數計入 |
| 第 8 欄 | **早退時數** | 平日早於 17:30 依規則計算；週末留白 |
| 第 9 欄 | **遲到時數** | 平日首次上班晚於員工設定的 workStart 時計算遲到時數；週末留白 |
